# Windows 免安装启动

将发行目录放在可写的位置，双击 **`一键启动.bat`** 或 **`非遗华裳.exe`**，浏览器会自动打开 **http://localhost:3001/**。关闭程序窗口或按 Ctrl+C 停止服务。

运行平台：Windows x64。运行时无需安装 Go、Node.js、pnpm、Python、C 编译器或额外运行库。前端页面、41 个 GLB、26 篇知识资料、40 件馆藏初始化数据、119 个热点及报告字体均包含在 EXE 中，模型不需要另行下载或手动解压。

## 首次运行

程序会在 EXE 旁生成 `.env`、`data/`、`knowledge/`、`seed/` 和 `reports/`，初始化独立数据库和演示账号。后续启动保留已有数据与配置。整个目录需要可写；迁移使用记录时，应将 EXE 与上述目录和 `.env` 一起复制。

- 普通用户：`user` / `user123`。
- 管理员：`admin` / `admin123`。
- 3001 端口需空闲；可在 EXE 旁 `.env` 修改 `PORT` 后重启。

离线时可以浏览馆藏、查看 3D、使用筛选、图表、收藏和报告。AI 问答、照片理解和云端语音需要网络及服务商 API Key；在 EXE 旁 `.env` 填写 `AI_API_KEY` 和相应模型配置后重启。未填 Key 时，AI 面板提示未配置，馆藏浏览仍可使用。EXE 不含开发者的真实 Key 或本地用户数据。

程序默认仅监听本机 `127.0.0.1`。命令行运行且不自动打开浏览器：

```powershell
.\非遗华裳.exe -open=false
```

## 从源码重新构建

构建电脑需要 Go 1.22+、Node.js 18.18+、pnpm 与 PowerShell 7，并准备清单对应的模型文件。在源码根目录运行：

```powershell
pnpm --dir client install --frozen-lockfile
pwsh -NoProfile -File .\scripts\构建单文件.ps1
```

输出位于 `release/windows-amd64/`。构建使用 `CGO_ENABLED=0`、`GOOS=windows`、`GOARCH=amd64` 和 `portable` 标签；Vue 生产资源由 Go 直接提供，模型备份、数据库、真实 `.env` 和依赖目录不参与嵌入。

源码开发入口为 **`开发启动.bat`**，使用 Go 与 Vite；**`一键启动.bat`** 优先使用已构建发行版，没有发行版时启动开发环境。原 `start.bat` 保留为兼容入口。
